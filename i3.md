# Legacy i3 Setup

The i3 configuration is retained as a reference for the previous X11 desktop setup. It is no longer actively maintained; Omarchy with Hyprland is the primary desktop environment.

## Configuration

The main configuration is `.config/i3/config`. Platform-specific variants are also retained:

- `arch/i3/config`
- `ubuntu/i3/config`

Supporting scripts live under `.config/i3/scripts/`, with additional Arch-specific files under `arch/i3/`.

## Components

The setup used:

- i3 with gaps as the window manager
- Picom as the X11 compositor
- Bumblebee Status for the top and bottom bars
- Dmenu as the application launcher
- i3lock and xtrlock for screen locking
- Xautolock for automatic locking
- Feh and the repository's background changer for wallpapers
- Dunst for notifications
- SXHKD as an optional X11 hotkey daemon
- NetworkManager and Blueman tray applets
- Alacritty and Kitty as terminals

Picom was started directly from the i3 configuration. It is not needed under Hyprland, which provides its own compositing.

## Installation Reference

The historical package installation script is `bin/install_requirements_i3.sh`. A duplicate remains at `tmux-switch.sh/install_requirements_i3.sh`.

The scripts contain separate Ubuntu and Arch package lists. They should be treated as historical references rather than run unchanged on a current system.

## Key Bindings and Behaviour

The main configuration includes:

- Ten named workspaces and workspace-specific application assignments
- Vim-style and arrow-key focus and movement
- Tiling, stacking, tabbed, floating, sticky, and scratchpad controls
- Screenshot, brightness, volume, Bluetooth, and display shortcuts
- Dedicated resize, move, wallpaper, and system-control modes
- Two Bumblebee Status bars with system metrics and multiple time zones

Refer to `.config/i3/config` for the complete binding and startup configuration.
